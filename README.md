# cv-plastontim — резюме как workflow

Интерактивное резюме под вакансию **«Специалист по автоматизации бизнес-процессов (ИИ-технологии)»** (ООО Пластонтим, Минск).

**Live:** [kerarty.github.io/cv-plastontim](https://kerarty.github.io/cv-plastontim/)

Холст в духе n8n: предустановленный сценарий автоматизации заказов Ozon/WB собран из нод —
вебхуки → ИИ-агент → SQL → WMS → Telegram-бот → мониторинг. Каждая нода раскрывается в два слоя:
что она делает в сценарии и какой опыт кандидата за ней стоит. Ноды можно таскать, порты —
соединять. Кнопка **Запустить сценарий** прогоняет заказ через конвейер: пакеты летят по рёбрам,
лог печатает ключевые факты, в финале открываются контакты и скрытые «честные ноды» (1С, Linux,
Ozon/WB API — про пробелы прямо).

**Кандидат:** Ярослав Кукар · Минск · [t.me/Kerarty](https://t.me/Kerarty) · [github.com/Kerarty](https://github.com/Kerarty)

## Дизайн-система

Тёмный редактор уровня Linear/n8n, собранный вручную — без UI-библиотек:

- **Иконки** — [`src/ui/icons.ts`](src/ui/icons.ts): единый stroke-набор 24×24 (стиль lucide/feather),
  красится через `currentColor` в цвет типа ноды. Никаких эмодзи.
- **Типографика** (все с полной кириллицей): Unbounded — дисплей и бренд, Onest — интерфейс,
  JetBrains Mono — технические подписи, теги, лог, статусбар.
- **Цвета типов нод** гармонизированы в один светловой уровень: триггер-янтарь, обработка-azure,
  ИИ-маджента, данные-зелёный, уведомления-циан, мониторинг-жёлтый, безопасность-коралл, резюме-серебро.
- **Атмосфера холста**: двухуровневая сетка (точки + перекрестия как в Figma), виньетка,
  два мягких свечения; при запуске сценария — «тёплое дыхание» света.
- **Моушен-слой**: каскадное появление нод при загрузке, hover-lift карточек и кнопок,
  пульс-волна на активной ноде, точечный поток по рёбрам, светящийся градиентный пакет.
  `prefers-reduced-motion` всё выключает.
- **Хром**: стеклянные (blur) топбар/палитра/статусбар, kbd-подсказки, зум-ридaут,
  терминальный `pipeline.log`, чипы с k-цветом в палитре и мобильном флоу.

## Стек

Vite + TypeScript, ноль рантайм-зависимостей — графовый редактор (ноды, безье-рёбра, drag&drop,
пан/зум, топологическая симуляция волнами Кана) написан с нуля. ~21 КБ gzip (JS 15.6 + CSS 5.4).

```
src/
  data/resume.ts     # весь контент резюме: ноды, рёбра, классическое резюме
  graph/world.ts     # рендер мира: ноды, рёбра, сетка, пакеты
  graph/interact.ts  # drag, пан, зум, соединение портов, удаление связей
  ui/simulate.ts     # симуляция прогона: волны Кана, пакеты, лог
  ui/icons.ts        # stroke-иконки 24×24
  ui/chrome.ts       # топбар, модалки (интро/контакты/классика), лог-док, тосты
  ui/palette.ts      # палитра нод: сценарий / резюме / скрытые
  ui/cards.ts        # карточка ноды: «В сценарии» + «Мой опыт»
  main.ts            # сборка всего + мобильный флоу
```

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # прод-сборка в dist/ (tsc + vite)
```

Деплой: GitHub Actions → GitHub Pages при пуше в `main`.

Параметры превью: `?nointro` — без входной модалки, `&autorun` — сразу запустить сценарий.

## PDF-версия

Кнопка **«Скачать PDF»** в топбаре отдаёт классическое двухстраничное резюме A4 с фото:
[`public/cv-yaroslav-kukar.pdf`](public/cv-yaroslav-kukar.pdf).

- источник — [`print/resume-print.html`](print/resume-print.html) (контент зеркалит `src/data/resume.ts`),
  регенерация: `msedge --headless=new --print-to-pdf=public/cv-yaroslav-kukar.pdf --no-pdf-header-footer --virtual-time-budget=9000 "file:///<abs>/print/resume-print.html"`;
- фотка взята из прошлого резюме-проекта (CBT), лежит в [`print/photo.png`](print/photo.png).
